# Changelog

All notable changes to Socratic AI. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [semver](https://semver.org/).

## 3.0.0 - 2026-09

The first release meant for people who are not the author.

### Added
- A native macOS app (`Socratic AI.app`, Apple Silicon) built with PyInstaller. Same UI as the browser version, in its own window, with a Dock icon. Closing the window shuts everything down and unloads the local models.
- A first-run Welcome page. It detects your memory, Ollama and ffmpeg, recommends a local model that fits the machine (qwen3 4b / 8b / 14b / 30b-a3b by RAM), downloads the models with a progress bar, or takes an API key instead.
- Streaming chat. Answers appear word by word in both Local and Cloud API modes.
- Any OpenAI-compatible API. A base URL field and presets for OpenRouter, Groq, DeepSeek and LM Studio; servers that reject `json_schema` fall back to `json_object` with local validation; embeddings can stay on Ollama when the provider has none.
- `socratic-ai-app` command (and `socratic-ai --native`) for the native window from a checkout.
- `PRIVACY.md`, `TERMS.md`, `SECURITY.md`, `CONTRIBUTING.md`, issue and PR templates, a `LICENSE` file (the README had claimed MIT since 1.0 without one).

### Changed
- Runtime data (SQLite, vectors, uploads, logs) moved from the working directory to the per-user data folder (`~/Library/Application Support/socratic-ai` on macOS). `SOCRATIC_DATA_DIR` overrides it.
- The generation cache is keyed by provider and model. Switching Local and API no longer serves a pack generated by the other model; the dashboard says which model produced it.
- Chroma opens on first use instead of at import, and without its default ONNX embedder.
- FastAPI lifespan replaces the deprecated startup event. The browser storage secret is generated per install.
- Ollama traffic uses `httpx`; `requests` is no longer a dependency.
- Ruff is the linter of record; CI runs it plus the unit and cassette tests, and builds the .app on tags.

### Fixed
- Editable installs ran stale copies of `main.py` and `config.py` from site-packages.
- `main.py` still called itself "Study Assistant API"; several docs still said OpenAI was the default.

## 2.3.0 - 2026-08 (unreleased)

- Local by default: Ollama for generation, chat and embeddings, parakeet-mlx (with mlx-whisper fallback) for transcription. One Local/API toggle flips every role; each mode keeps its own model bundle. No API key needed to start.
- Real structured outputs on Ollama (the schema is passed as `format`), explicit `num_ctx` per stage, `keep_alive` between stages, batched `/api/embed`.
- Vector collections keyed by embedding model, with the task prefixes `nomic-embed-text` expects.
- Provider-aware concurrency (8 hosted, 2 local), fail-fast on bad model names or keys, SQLite in WAL mode, live per-stage progress in the UI.

## 2.2.0 - 2026-06

- A single document now yields a full pack: takeaways, synthesis, apply-it scenarios and a quiz.
- Ledger extraction runs as parallel map-reduce; sources build concurrently; insights and quiz are two parallel calls. A fresh run went from N serial round-trips to about 4.
- Section audit and chat depth classifier are plain code, not model calls. Chat is one call per turn.
- Uploads land the moment you add a file; alt-tabbing no longer resets the page.

## 2.1.0 - 2026-06

- NiceGUI UI mounted on the FastAPI app: one process, one port. Streamlit removed.
- In-app Settings page: provider, models and key switchable at runtime.
- Interactive quiz that locks on first pick and hands off into the chat.
- `uv run socratic-ai` replaces the PyInstaller binaries and the venv launcher.

## 2.0.0 - 2026-05

- Iterative accumulation pipeline replaces the novelty-ledger machinery (about 4x less code).
- Key concepts get both a plain-language and a technical definition.
- Pluggable LLM backend (OpenAI or Ollama per role).

## 1.0.0 - 2026-05

First tagged release: FastAPI backend, Streamlit frontend, OpenAI only.
